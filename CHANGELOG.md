# Changelog

All notable changes to this dataset are documented here. Versions follow [Semantic Versioning](https://semver.org/): a new major version renames or removes columns.

## [1.0.0] - 2026-10-15

### Added
- 167 countries and territories, 53 typed columns, in CSV, Parquet and JSON.
- Data dictionary in English and Portuguese, methodology and data quality report.
- `scripts/build.py`, `scripts/validate.py` and `scripts/docs.py`; validation in GitHub Actions.
- Kaggle metadata (`data/dataset-metadata.json`) and exploratory notebook.

### Fixed (relative to the raw export)
- 18 classes of problems, listed in `docs/data-quality.md`.
