## Conventions

- Encoding UTF-8 without BOM, comma separated, header in the first line, `\n` line endings.
- Lists inside a cell use `|` as separator (`MNE|GRC|MKD`). Commas inside values are never used as separators.
- Booleans are `True` / `False`. Empty cell = unknown or not applicable.
- Decimal point is `.`; no thousands separator.
- Text values that are labels for readers are in Portuguese (`*_pt`); technical enumerations are lowercase English codes (`ltr`, `monday`).
